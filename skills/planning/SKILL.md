# planning

**Trigger:** Load after `design-doc` or `diagnostic`, before writing any file.

| Step | Content |
|------|---------|
| 1 | State your understanding of the task in 2–3 sentences |
| 2 | List every file you will touch and why, one line per file |
| 3 | Identify one thing that could go wrong and how you will check for it |
| Gate | Do not write any file until all three steps are complete. If the task changes mid-execution, re-run steps 1–3 before continuing. |
